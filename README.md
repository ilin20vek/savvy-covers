# SAVVY: обложки постов

Публичный хостинг картинок для постов SAVVY. Здесь только обложки - те же, что
уходят в каналы вместе с текстом. Ни данных, ни ключей, ни черновиков текстов.

Зачем публичный репозиторий: Telegram собирает превью только с адресов на
стандартных портах (80/443). Свой сервер обложек раздаёт их по `:8080` -
Telegram такой адрес не принимает (`WEBPAGE_URL_INVALID`), а занять 80-й порт
на сервере нельзя. GitHub отдаёт файлы по https, и превью собирается.

Адрес картинки:

```
https://raw.githubusercontent.com/ilin20vek/savvy-covers/main/<папка>/<файл>.png
```

| Папка | Куда идут обложки |
|---|---|
| `tg/` | посты телеграм-канала |
| `dzen/` | статьи Дзена |
| `vc/` | лонгриды VC.ru |

Файлы кладёт `social/publish_images.py` из рабочего репозитория: копирует
картинку сюда, коммитит, пушит и отдаёт готовые ссылки.
